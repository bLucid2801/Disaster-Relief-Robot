# Disaster-Relief-Robot
My CoppeliaSim Disaster Relief Robot
Intro:
This project was my solution to a basic Disaster Relief Robot. This project involved creating a prototype robot based off of CoppeliaSims' Bubble Rob robot. I added two additional proximity sensors; one to help prevent Bubble Rob from getting stuck in tight corridors and another to scan for any humans in vicinity. This robot's functionality could be improved by adding better robot navigation. Furthermore, the robot's capabilities could be improved by utilizing reinforced learning and searching algorithm's. 

Requirements: 
1. Go to https://www.coppeliarobotics.com/ and download the educational simulator 
2. Download my simulator file to run and experiment
